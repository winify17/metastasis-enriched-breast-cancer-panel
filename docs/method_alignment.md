# Method alignment notes

The code follows the analysis that produced the dissertation tables and figures. Several passages and table cells in the current dissertation draft should be revised so that the written account describes that analysis exactly.

## AURORA candidate filter

The current Methods section states that genes with at least five mutation-positive metastatic patients were carried forward. Applied alone, this condition retains 45 genes. Results section 3.2, Figure 1, and the analysis code also require the gene to be metastasis-enriched, which retains 10 genes.

Suggested Methods wording:

> Among genes with a higher mutation frequency in metastatic than primary tumours, genes mutated in at least five of the 39 metastatic patient profiles were carried forward for TCGA-BRCA prevalence screening.

## Receptor-derived subtype

The current Methods section states that patients with missing or indeterminate receptor information were assigned to Unknown. The archived analysis used a partial-information rule. Hormone-receptor positivity was assigned when either ER or PR was positive. If neither available result was positive and HER2 was known, the tumour was classified as HER2-positive or triple negative according to HER2, even when ER or PR was unrecorded. Cases without sufficient HER2 information, or with no receptor results, were assigned to Unknown.

Six patients had incomplete receptor data but were classified under this rule: two as HR+/HER2-, one as HER2+, and three as triple negative. Two of the six had an overall-survival event. This produces the dissertation subtype counts, including 365 patients in Unknown, and the reported Cox estimates.

Suggested Methods wording:

> Hormone-receptor positivity was assigned when either ER or PR was positive. Tumours with no recorded positive ER or PR result were classified as HER2-positive or triple negative when HER2 status was available, including cases with an unrecorded ER or PR result. Cases without sufficient HER2 information or with no receptor results were retained in the Unknown category.

Changing the code so that any missing receptor result forces Unknown would increase that group from 365 to 371. It would also change the Model 3 panel estimate from HR 1.200 (p=0.175) to approximately HR 1.205 (p=0.165), requiring corresponding updates throughout the dissertation.

## Interpretation of the paired burden test

The seven-gene burden was compared in the same 39 AURORA pairs used for directional and recurrence-based selection. The Wilcoxon result is therefore a descriptive post-selection summary, not independent confirmation of metastatic enrichment.

## Metastatic burden category in Table 4

The current Table 4 reports nine metastatic cases with burden >=3. The underlying paired data contain nine cases with burden 3 or 4 and two additional cases with burden 5, giving 11 cases (28.2%) with burden >=3. The reported metastatic categories otherwise sum to 37 rather than 39, confirming that the two burden-5 cases were omitted from that row.

Suggested Table 4 correction:

> Patients with burden >=3: 11 (28.2%) in the metastatic column.

The code generates the corrected value of 11. No analysis estimate changes because this is a descriptive category label; the mean, median, range, and Wilcoxon test already include both burden-5 cases.

## Individual-gene C-indices in Supplementary Table 7

The column is labelled `Multi. C-index`, but the last three rows report values from the TMB-adjusted models rather than the clinically adjusted multivariable models. The clinically adjusted C-indices generated by the models are 0.767 for GOLGB1, 0.768 for COL14A1, and 0.770 for MUC5B. The current table instead gives 0.765, 0.766, and 0.769, which are the corresponding TMB-adjusted C-indices rounded to three decimals.

Suggested Supplementary Table 7 correction:

> Replace the final three `Multi. C-index` entries with 0.767, 0.768, and 0.770. The first four entries already use the clinically adjusted model.

The same TP53 row reports a clinically adjusted upper 95% confidence limit of 2.19. The fitted value is 2.1848176614468, which rounds to 2.18 at two decimal places. Replace `1.49 (1.01-2.19)` with `1.49 (1.01-2.18)` in that row.

## Reproducibility appendix

The current reproducibility paragraph names superseded output files, includes the patient-level `panel_burden_aurora.csv`, and refers to ten in-text tables. The dissertation contains six main data tables and nine supplementary tables. The patient-level AURORA file should not be named as a public repository item.

Suggested replacement:

> Reproducibility materials: The public repository contains the analysis scripts, the archived public TCGA-BRCA inputs, schemas for the controlled AURORA inputs, and a complete output manifest. Uncleared AURORA aggregate files and all patient-level AURORA data remain outside the public repository. In an authorised environment supplied with the required AURORA inputs, the workflow generates six main data tables, nine supplementary tables, and ten figures covering panel construction, paired burden, TCGA burden and TMB, Cox models, sensitivity analyses, individual-gene estimates, proportional-hazards diagnostics, model concordance, and Kaplan-Meier analyses. Generated tables and figures are excluded from the repository and can be recreated by following `docs/output_manifest.md`.

## Title and interpretation

The title describes the genes as independent prognostic markers, although the primary seven-gene panel was not associated with overall survival after adjustment. A neutral title would fit the findings more closely:

> Identification and Prognostic Evaluation of Metastasis-Enriched Genes in Breast Cancer through Integrated Analysis of Somatic Mutation Data from Public Genomic Datasets

Results section 3.3 should describe the paired burden test as a post-selection, descriptive comparison. Survival outcomes were not used to form the panel, but the directional and recurrence filters and the burden comparison used the same 39 AURORA pairs.

Discussion statements that the negative prognostic result supports an evolutionary bottleneck should use more cautious language. The observations are consistent with context-dependent selection, but no phylogeny, clonal fitness measurement, or formal comparison between metastatic enrichment and prognostic association was performed. Likewise, the conclusion can state that the findings illustrate a possible distinction between metastatic enrichment and diagnosis-time prognosis, rather than demonstrate that the two are distinct genomic properties.
