# Data inputs

## AURORA controlled inputs

| File | Purpose |
|---|---|
| `aurora_cohort_summary.csv` | Non-identifying cohort totals used for Table 1 |
| `aurora_mcnemar_results.csv` | Genome-wide paired McNemar results used for Table 2 and candidate selection |
| `aurora_candidate_genes.csv` | Ten metastasis-enriched genes with `n_met >= 5` |
| `panel_selection.csv` | Ten candidates with TCGA mutation counts and the final inclusion flag; regenerated by the public pipeline |
| `final_panel_genes.csv` | Ordered seven-gene panel used downstream |
| `aurora_paired_burden_counts.csv` | Aggregated primary-metastatic burden pairs used for Table 4 and Figure 2 |

The restricted AURORA mutation file, individual-level mutation states, and uncleared aggregate CSV files are not included in the release directory. Although the aggregate files have no direct patient identifiers, several contain small cells. They must remain in the controlled analysis environment until written disclosure approval or an approved small-cell rule is available. The required schema and provenance record are described in `aurora/RESTRICTED_INPUT_SCHEMA.md`.

## TCGA raw snapshot

| File | Purpose |
|---|---|
| `tcga_brca_clinical_raw.csv` | Patient clinical attributes from `brca_tcga` |
| `tcga_brca_mutations_raw.csv` | Somatic mutations for the ten AURORA candidates |
| `tcga_brca_tmb.csv` | Sample-level `TMB_NONSYNONYMOUS` values |

The snapshot was assembled on 25 August 2026. Use the archived files for exact manuscript reproduction. Running `python/02_tcga_download.py` retrieves the current cBioPortal records instead. TCGA processing uses sample type 01 for both mutation status and TMB. Type 06 metastatic samples are not used in the diagnosis-time analysis.

## TCGA processed input

`tcga_processed/tcga_brca_panel_survival_input.csv` is regenerated by `python/04_tcga_cleaning.py`. It contains 1,083 patients, 151 deaths, clinical covariates, TMB, panel burden, and seven binary mutation indicators.

The molecular subtype rule used to generate the manuscript values is recorded in `docs/method_alignment.md`.

`SHA256SUMS` records the checksums of the archived inputs used for dissertation reproduction. Entries for controlled AURORA files can be verified only in the authorised analysis environment.
